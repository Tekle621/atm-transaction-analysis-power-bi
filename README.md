# ATM Transaction Analysis Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze ATM transaction activity, customer demographics, and regional performance.

## Key Insights
- **150** ATM transactions analyzed
- **1.392M** total transaction amount
- **66** customers represented
- **32.7%** transaction share from withdrawals
- **3** locations: Addis Ababa, Sidama, and Dire Dawa
- Customer segmentation by age, gender, and occupation

## Tools Used
- Microsoft Power BI
- Power Query
- Data Visualization
